# DISSERTATION-WORK
THIS REPOSITORY CONTAINS THE WORK I DID IN ORDER TO GET A MASTER DEGREE IN PHYSICS.

THE PRESENT REPOSITORY CONTAINS SOME NUMERICAL ROUTINES TO CALCULATE TRANSPORT PARAMETERS IN TOPOLOGICAL INSULATORS FOR TWO DIMENSIONAL LATTICES CONTAINING
CERTAIN SYMMETRIES (GROUP D4h CORRESPONDING TO THE USUAL SQUARE LATTICE). THE CURRENT CODE CAN BE EASILY MODIFIED, BY REDEFINING APPROPRIATE FORMULAS TO COMPUTE THE EIGENVALUES AND THE CORRESPONDING BERRY PHASE TO A CERTAIN HAMILTONIAN FOR A MAGNETIC SYSTEM.

THESE NUMERICAL ROUTINES WHERE WRITTEN IN THE FORTRAN PROGRAMMING LANGUAGE (FORTRAN 90/95/03 STANDARD). SOME SCRIPTS WRITTEN FOR GNUPLOT ARE ALSO AVAILABLE. THEY WERE USED IN MY FINAL WORK TO PLOT SOME DATA.
